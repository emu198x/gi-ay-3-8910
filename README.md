# gi-ay-3-8910

The General Instrument AY-3-8910 programmable sound generator, with its single-port AY-3-8912 facade.

| Crate | Registry |
|---|---|
| [`emu198x-gi-ay-3-8910`](crates/emu198x-gi-ay-3-8910) | [crates.io](https://crates.io/crates/emu198x-gi-ay-3-8910) |
| [`emu198x-gi-ay-3-8912`](crates/emu198x-gi-ay-3-8912) | [crates.io](https://crates.io/crates/emu198x-gi-ay-3-8912) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Spectrum 128, Amstrad CPC, MSX, Oric and other machines, and by Play198x for `.ay` playback.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
